## 2. 玻璃

只用在四处：面板背景、手机传送带、边缘图标底、返回胶囊。

```css
.glass {
  background: var(--glass);
  backdrop-filter: blur(28px) saturate(180%);
  border: 1px solid var(--glass-line);
  box-shadow: var(--shadow-panel), inset 0 1px 0 rgba(255,255,255,0.6);
}
```

**性能红线：**

- 不给 iframe 容器加 `backdrop-filter`
- 动画只动 `transform` / `opacity`，不动 `blur()`、`width`、`height`
- 面板进出用 `translateX`
- 目标：iPad 第 9 代 50fps

iPad 上大面积玻璃叠在 iframe 上会掉帧。宁可少一层玻璃，也不要掉帧的无感。

## 3. 参考

项目根目录下有个 `设计参考/` 文件夹，里面是一个 `.html`，包含设计规范和全部截图。**那是唯一视觉基准。**

### 3.1 怎么用这份参考

**照抄，不要提炼。**

反面做法是看完图之后，写一份"颜色/圆角/字号"的汇总表，再照表写代码。这个过程每转一手都会掉东西——玻璃的层次、阴影的柔和度、字距的呼吸感、卡片之间的比例，全都死在"提炼"两个字上。最后出来的东西"规范上没错，但就是不像"。

正确做法：

1. `ls 设计参考/`，找到里面的 `.html`。
2. 读它的源码。看图都放在哪，CSS 都写了什么。**这份 HTML 本身就是设计系统**，里面的变量、类名、间距值直接可用。
3. 逐张 `Read` 它引用的图片。不是扫一眼，是当真图看。
4. 写项目第一行 CSS 时，**先复制它已有的样式**，再改内容。没有的东西才新写。
5. 每做完一个页面，把参考的样式规则和你写的贴在一起比一遍。对不上就改回参考的值，不要用"我看着差不多"过去。

**参考里有的，原样搬。** 它写 `28px` 就用 28，不要因为"28 不整"改成 24；它用了 `letter-spacing`，就留着。这些细节正是"像"和"不像"的分界。

**那个文件夹只读不改。** 它不是项目的页面，不进构建，不挂路由，不放 `public/`，Vite 的 `build.rollupOptions` 里排除掉。看完了就放着，改它等于改基准。

**如果里面的 HTML 叫 **`index.html`，先改名成 `design-reference.html`。虽然它在子目录里，但有些静态服务器会把它当目录首页。改名只改文件名，内容不动。

**如果图片是 base64 内联的**（`src="data:image/png;base64,..."`），别直接 `Read` 整个文件——几 MB 的 base64 会一次吃掉上下文。先 `wc -c` 看多大，然后用脚本把每张 `data:` 图拆成独立文件存进 `/refs`，再逐张 `Read`。拆出来的只是副本，原 HTML 不动。

### 3.2 参考没覆盖的地方

参考图是别人的产品，有房间页、右侧面板、线索流这些它没有的界面。这些必须自己延伸，规则是：

- 新界面只允许用参考里出现过的**颜色、圆角、间距档位、字号档位**，不许新增数值
- 需要新元素（比如边框、分割线）时，先在参考 HTML 里找最接近的那个，照着做
- 实在找不到，选更少装饰的那个，并在 `DECISIONS.md` 记一行"参考未覆盖，我选了 X，因为 Y"

**不要创新。** 这个项目的视觉全部来自那份 HTML，你只负责把它铺到更多页面上。

### 3.3 `设计参考/` 是空的

那是搞错了，不是可以自由发挥。先在 `DECISIONS.md` 记一行"未见设计参考"，然后按下面这段做，做完在进度里标红：

> 米白底，墨绿主色，大圆角卡片，卡片几乎无边框只用极淡投影，标题字号克制，数字用等宽，整体像一张银行 App 的首页，而不是工具后台。

**不要因为没图就停下来等。**

## 4. 断点

| 断点 | 布局 |
| --- | --- |
| `< 768` 或竖屏 | 手机：iframe 全屏 + 底部抽屉 |
| `≥ 768` 且横屏 | iPad：iframe 居中 + 右侧面板 |

不做中间态。这两个之外没有第三种布局。

## 5. 文案

读 `docs/文案与设计参考.md`，调性**克制专业**。

几条最容易违反的：

- 按钮用行业通行说法，不创新。`开始`、`取消`、`发出去`。
- 错误提示要说清下一步。`这个网页不支持嵌入。试试打开新窗口。`
- 空状态写场景，不写"暂无数据"。
- 不用感叹号。
- 不写"不是 X，而是 Y"。
- 不排比凑三项。
- 不写"赋能、闭环、打通、链路、颗粒度"。

具体的几句，直接用：

| 位置 | 文案 |
| --- | --- |
| 首页主标题 | `几个人一起玩网页解谜` |
| 首页副标题 | 不写 |
| 输入框占位 | `粘贴游戏链接` |
| 推荐区标题 | `推荐` |
| 房间号入口 | `有房间号？` |
| 配置页主按钮 | `开始` |
| 模块说明 | `开了全员可见，进房后不能改。` |
| 流空状态 | `还没有人发东西。` |
| 搜索占位 | `搜点什么` |
| 引导提示 | `从右边划一下，能看到大家发的东西。` |
| 断线 | `连接断了，正在重连` |
| 代理失败 | `这一页可能没加载完整。` |
| 过期提示 | `这个房间已于 X 月 X 日到期。` |
| 到期提醒 | `这个房间还有 1 天到期。要留个底吗？` |
| 房间不存在 | `没有这个房间。看看房间号对不对。` |
| 限流 | `试得太快了，等一分钟。` |
| 链接不完整 | `这个链接不完整。让房主再发一次。` |
| 网址错 | `这不像一个网址。` |
| 打不开 | `这个网址打不开。检查一下链接。` |
| 嵌入失败 | `这个网页不支持嵌入。` |
| 切直连确认 | `游戏里的存档会重新开始。` |
| 代理链接失效 | `链接已失效，刷新一下。` |
