# 04-流与笔记

# 多人 ARG · 流与笔记

**这份管**：流怎么排、头像条、星标和排除、成员状态、四个笔记模块、公共搜索、输入框语法。
**这份不管**：数据怎么存（02）、搜索框长在面板哪个位置（01 §2.3）。

---

## 1. 流

所有 item 按 `createdAt` 倒序，新的在下面，聊天式。

| 类型 | 长什么样 |
| --- | --- |
| 网页 | 卡片。左边 3px 竖线用作者色，标题两行截断，下面一行小字 `小林 · 12:40`。右上角一个小图标表示"这页我看过"（本地记录，不同步） |
| 笔记 | 一行文字，前面一个作者色小圆点。星标的行前面是实心星 |
| 评论（带 `refId`） | 缩进 16px，字号小一档，前面一条短竖线 |
| 系统 | 居中灰字 12px，如 `小林 加入了` |

空状态：`还没有人发东西。`

---

## 2. 头像条（"每人一栏"的实现）

**只在"笔记"视图里出现**，流里不放（流本来就是混排的，再按人切会切成碎片）。

笔记视图顶部固定一条：

```
[全部] [我]  ● ● ●  ★
```

- 前两个是文字胶囊，中间是头像圆点（名字首字 + 成员色），最后是星标。
- 点谁 → 只显示他的 item。
- 点 ★ → 只显示 `starred && status !== 'excluded'`。
- 有未读的成员，圆点右上角一个 4px 的小点。
- **不需要"切换页面"，切换的只是过滤条件。** 5 个人也不用 5 个 tab。

默认停在"全部"。理由：一起玩的时候，读别人的东西是高频动作；写自己的反而是低频。

---

## 3. 星标与排除

> 这里说的"公共区"就是第 2 节那条头像条最右边的 `★` 视图，不是另一个页面，也不是新加一个 tab。

每行右侧，hover 或长按出现两个图标：`star` 和 `x`。

- `star` → `starred = true`，进公共区
- `x` → `status = 'excluded'`，变灰，从公共区消失，留在流里

公共区顶部显示：`待验证 8 · 已排除 12`。点"已排除"展开灰名单。

**"已排除"比"已确认"重要。** 这类游戏最大的浪费是五个人各自把同一个错误答案试一遍。灰名单是团队的集体记忆，别省。

---

## 4. 正在看哪一页

成员列表里每行末尾显示 `正在看《店内环境》`。

- 数据来自 bridge 的 `url` + `title`，节流 5 秒上报
- 超过 5 分钟没更新就不显示
- **不要在 iframe 上画别人的光标或选框。** 那需要同页协作，这里做不到

## 5. 模块

从分段控件进入，每个模块是独立视图，数据都来自 `items`。

### 5.1 人物关系

- SVG 画布，`dagre` 做层次布局。**不要用力导向**，每次刷新位置会变，用户会晕。
- 节点：圆角矩形 120×48，首字 + 名字，成员色描边。
- 边：贝塞尔曲线，中间标签（`弟弟`）。
- 单指拖节点微调，双指缩放画布，双指平移。
- 顶部 `+` 加人，点节点弹"加关系"。
- 节点上限 50，超过折叠成 `其他 12 人`。
- 手机端只读。

### 5.2 关键词

两列表：词 / 结果。结果用 `命中`（绿）/ `未命中`（灰）标签。

顶部输入行，格式 `词 = 命中` 或 `词 = 未命中`，回车即存。

### 5.3 密码本

卡片列表。每张：账号、密码（默认打码，点眼睛显示）、用途、`已验证` 开关。

`已验证` 是必须的。这类游戏的密码经常是"猜出来的但没人试过"，没有这个开关，三个人会拿着同一个密码各试一遍。

### 5.4 时间线

竖线 + 节点，按 `event.at` 排序。

## 6. 公共搜索

面板内容区顶部常驻一个框，占位符 `搜点什么`。

行为按房间能力分两种，用户不需要知道区别：

| 房间状态 | 搜什么 |
| --- | --- |
| `game.hasSearch = true` | 先出两栏：`在游戏里搜「符咒」` / `我们记过 3 条` |
| `game.hasSearch = false` | 只搜本地：笔记、关键词、密码用途、人物名 |

- 点"在游戏里搜" → **不广播**，只把当前 iframe 跳到结果页，参数名从 `game.searchParam` 取（默认 `q`）。这是个人探索，不该替别人导航。
- 想让大家一起看，点结果旁边一个 `发给大家`，才会进流。
- 本地搜索是纯前端过滤，输入即出，200ms 防抖。
- 框右侧一个小按钮 `词`：把当前词存成 keyword item，默认 `未命中`，等验证。

**为什么搜索不广播**：五个人各查各的，把别人的画面突然切走是最讨厌的事。共享的是结果，不是导航。

## 7. 输入框的快捷语法

流底部输入框支持三个前缀，其余当普通笔记：

| 输入 | 变成 |
| --- | --- |
| `词 符咒 = 命中` | keyword |
| `密 贴吧 / abc123 / 顾铭账号` | secret |
| `@小林 这页你看下` | note，带 mentions |

不做自然语言解析，就这几个硬前缀。输入框上方一行 11px 灰字：`词 xxx = 命中 · 密 账号 / 密码 / 用途`。
