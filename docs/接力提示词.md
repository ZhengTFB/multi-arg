## 你的任务

在 `d:/Desktop/多人ARG` 实现一个叫「多人 ARG」的网页应用：三到六个人约好一起玩同一个网页解谜游戏，各自在自己的浏览器里翻页，看到什么就丢进共享房间，别人点开直接到那一页。

**先做完 Phase 0 和 Phase 1（脚手架 + 全部静态 UI + 四张截图），停下来向用户汇报，等他说继续，再把 Phase 2 到 Phase 7 一口气做完。**

## 一、这个项目是什么（三句话，先看懂再动手）

- 房间共享的是**一条流**，不是一块屏幕。每个人有自己的浏览器状态，进度各不相同。**不做跟播，不做同步滚动，不做共享屏幕。**
- 游戏是第三方的静态站，用 iframe 嵌进来。不改作者的代码。
- 跨域 iframe 读不到 URL。所以要写一层 HTML 代理，让"谁到了哪一页"可被感知。这是产品成立的技术前提，不是可选优化。

**这个页面的写法要知道**：颜色和圆角写在**行内 `style`** 上；class 里只有版式（`flex`、`gap-3`、`px-5`、`py-2.5`、`text-sm`、`font-medium`、`transition-all`、`duration-500`、`ease-in-out`、`hover:translate-y-0.5`、`active:scale-95`）。两边都要抄。

### 照抄的规则

1. 先 `Read` `recipes.md` 和 `section-components.html`，把八张切片也看一遍。
2. 写第一行 CSS 时，**先把参考里的值搬过来**，再改内容。参考里没有的才新写。
3. 参考写了 `22px 26px 20px 24px / 20px 22px 26px 22px` 就用这个值，不要因为"不好看"或"不整"改成 `16px`。
4. 每做完一个页面，把参考的规则和你写的贴在一起比一遍。对不上就改回参考的值。

**圆角是这个风格的签名，成对的不等角**，四种档位，按用途选：


页面里还有 `50% 40% 50% 40% / 40% 50% 40% 50%` 这类纯装饰用的漂移圆角，那是插画元素，不要用在按钮上。

**边框与阴影**

```css
border: 1px solid #E9E0D4;              /* 白卡默认边框，17 次 */
border: 1.5px solid #C4B5A5;            /* 次级描边 */

box-shadow: 0 6px 16px rgba(92,64,51,.3);
```

**字体（硬约束：不许引 Google Fonts）**

参考页用 Kalnia（衬线标题）+ Commissioner（正文）+ Fragment Mono（数字）。国内加载 Google Fonts 会拖慢首屏，所以换成系统栈：

```css
--font-display: "Songti SC", "Noto Serif SC", Georgia, "STSong", serif;  /* 标题 */
--font-body: -apple-system, "PingFang SC", "Noto Sans SC", system-ui, sans-serif;
--font-num: ui-monospace, "SF Mono", Menlo, Consolas, monospace;         /* 房间号、密码、数字 */
```

标题字重 600-700，`letter-spacing: -0.01em`；小标题用 `uppercase` + `letter-spacing: 0.2em`（参考里 `tracking-[0.2em]` 出现 7 次）。

**缓动**：参考全站 `duration-500` / `duration-700` + `ease-in-out`，hover `translate-y-0.5`（下移 2px），active `scale-95`。原则是 "Slow / Intentional Pace"。项目的动效规范照这个：进场 320-450ms，出场 200-280ms，`cubic-bezier(0.22,1,0.36,1)`，只动 `transform` / `opacity`。不做弹跳过头的玩具感。

### 不搬的东西

参考页是英文营销站，本项目是中文工具界面。只搬材质、色彩、圆角语言、字体层级、间距档位。

**不搬**：hero 大标题、营销区块、页脚、装饰性叶子和大色块、六段式长页结构。首页结构按 `01-页面与布局.md` §1.1 来（一屏，输入框是主体），只是穿着 Natural Organic 的皮。

### 参考没覆盖的界面

房间面板、边缘缝、传送带、抽屉、流卡片、笔记行，参考图里都没有。规则：

- 只用上面出现过的**颜色、圆角档位、边框、阴影、字号档位**，不许新增数值
- 需要新元素时，先在 `page.html` 里找最接近的那个，照着做
- 实在找不到，选更少装饰的那个，在 `DECISIONS.md` 记一行

**不要创新。** 这个项目的视觉全部来自那份参考，你只负责把它铺到更多页面上。

## 六、15 条硬约束

见 `00-总纲.md` 第五节速查表。最容易违反的四条单独提醒：

1. iframe 容器固定 **430×932**，`scale = min(可用高/932, 可用宽/430)`，宽度不随面板收放变化。
2. 面板展开时 **iframe 不位移、不变暗、不缩放**，也不给 iframe 容器加 `backdrop-filter`。
3. 一条 item **只有作者能改**，别人只能新建带 `refId` 的评论。所以不需要 CRDT。
4. `/p?u=` **必须校验 HMAC 签名**，否则就是一个公开免费代理。

## 九、这个环境已经踩过的坑

1. **`wrangler dev` 起不来。** 本机 workerd 报 `access violation` / `thread 'main' overflowed its stack`，最小 Worker 也复现，提示 VC++ Redistributable 过期。**不要为此安装系统组件、不要重试第三次。** `vite build` 能过就继续做，原因记 `DECISIONS.md`，实机互通留到线上验。
2. **`workers.dev` 在本网络可能连不上。** `curl` 超时（143 网段被阻断），`api.cloudflare.com` 正常。部署本身能用，线上自检可能做不了；照实写进 `DEPLOY.md`，不要当成部署失败。
3. **TypeScript 装成了 7.x。** 如果 `tsc --noEmit` 因为 tsconfig 选项报错，直接 `npm i -D typescript@5.9` 降回去，别在版本兼容上耗时间。
4. **Playwright 浏览器版本对不上。** 本机有 chromium-1243，playwright 1.64 要 chromium-1248。两条路：`npx playwright install chromium`（要下载），或者直接用系统 Edge：

```js
const browser = await chromium.launch({ channel: 'msedge' });
```

截图脚本用后者，快且不下载。
5. **`设计参考/` 不能进构建。** 不挂路由、不放 `public/`、`build.rollupOptions` 里排除。
6. **`/p` 不带 `accept-encoding`。** 带了会拿到压缩流，HTMLRewriter 直接报错。
7. **`base` 用 `response.url`，不是请求里的 `u`。** fetch 跟过重定向后最终地址可能不一样。
8. **图片一个字节都不过 Worker**，非 HTML 一律 302 回原站。这是免费额度撑得住的唯一原因。
