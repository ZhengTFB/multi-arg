## 1. 导出与导入

### 1.1 导出什么

一个 JSON，一个 Markdown。**不打包成 zip**，直接给两个下载，简单可靠。

JSON：

```json
{
  "v": 1,
  "exportedAt": 1730000000000,
  "room": { "id": "8472", "createdAt": 0, "game": {}, "modules": [] },
  "members": [{ "name": "小林", "color": "#07444C" }],
  "items": []
}
```

**不含 token。** 导出是要发给别人看的东西，带上 token 等于把房间送人。

Markdown：

```markdown
# 大学生登山失踪事件
2026-10-30 至 2026-11-06 · 4 人

## 关键词
- 符咒 — 命中
- 添福菩萨 — 未命中

## 密码
- 贴吧 / abc123 / 顾铭账号（已验证）

## 人物
- 顾铭 — 顾晴的哥哥

## 笔记（按时间）
- 12:40 小林：第三页右下角有个小字
```

### 1.2 从哪导出

三处：

1. 成员列表底部，一行小字 `导出`
2. 到期提示条上的 `导出`
3. 过期只读页面右上角

### 1.3 导入

配置页底部 `用上次的配置新建` → 选 JSON → 预填项目链接和模块 → 起名字 → 开始。

**不导入 items。** 新房间是干净的，旧笔记只作参考（用户自己看 Markdown）。

理由：把上一局的笔记灌进新房间，等于开局就剧透自己。用户真想带过来，导出 Markdown 自己贴。

## 2. wrangler

### 2.1 wrangler.toml

```toml
name = "multi-arg"
main = "worker/index.ts"
compatibility_date = "2026-10-01"
compatibility_flags = ["nodejs_compat"]

[assets]
directory = "./dist"
binding = "ASSETS"
not_found_handling = "single-page-application"

[[durable_objects.bindings]]
name = "ROOM"
class_name = "RoomDO"

[[migrations]]
tag = "v1"
new_sqlite_classes = ["RoomDO"]
```

### 2.2 命令

```bash
npm run build
npx wrangler deploy

# secret 必须用管道写，不带参数会等 stdin，无人值守会卡死
echo "$PROXY_SECRET" | npx wrangler secret put PROXY_SECRET
```

`PROXY_SECRET` 由用户生成（`openssl rand -hex 32`），在环境变量里。**如果这个变量是空的，先自己生成一个随机的，写进 **`.dev.vars`**，再用它上线**——不要因为没值就跳过，代理签名会失效。

`wrangler deploy` 认环境变量里的 `CLOUDFLARE_API_TOKEN` 和 `CLOUDFLARE_ACCOUNT_ID`，不要去 `wrangler login`——那个要开浏览器点授权，夜里没人点。Token 至少要有 Workers Scripts:Edit、Durable Objects:Edit、Workers KV/Static Assets 的权限，不够会报 10000 或 9109。

环境变量由用户提供。**不要写进仓库**，不要提交 `.env`、`.dev.vars`。

## 3. 部署后自检

1. `npx wrangler tail` 看有没有报错
2. 打开 `<worker>.workers.dev`，跑一遍：

- 建房间 → 拿到 4 位号
- 两个浏览器窗口进同一房间
- 一边发链接，另一边收到
- 代理页面正常加载，图片能显示
- 面板里的"正在看"跟着变
- 手机尺寸下抽屉能拉出来
- 二维码扫出来能直接进房
- 断开网络再恢复，能自动重连

1. 结果写进 `DEPLOY.md`，附截图。有失败项写清楚失败在哪一步、报什么错。

### 3.1 部署失败也不能停

晚上没人能给你改 Token、点后台按钮。按这个顺序处理，最多试三轮：

1. **401 / 403**：Token 权限不够或没生效。删掉 `node_modules/.wrangler` 里的缓存重试一次；还不行就是权限问题，记进 `DEPLOY.md`，跳过部署，继续做完剩下的 Phase。
2. **DO 绑定报错**：确认 `migrations` 里是 `new_sqlite_classes` 不是 `new_classes`。`new_classes` 建出来的 DO 没有 SQLite。
3. **静态资源 404**：确认 `[assets] directory = "./dist"` 且 `npm run build` 先跑过。
4. **域名解析没生效**：忽略，用 `<worker>.workers.dev` 测。

**三轮不通就停手，别耗一整晚。** 把错误原文贴进 `DEPLOY.md`，在 `进度.md` 里写一句 `部署未完成，原因见 DEPLOY.md`，然后把项目收拾干净交付。

本地能跑、线上没通，是完全可以接受的交付状态。用户醒来补一个 Token 就能部署。

### 3.2 交付状态怎么写

`DEPLOY.md` 开头一句，三选一：

- `已上线：https://xxx.workers.dev`
- `本地可跑，线上未完成：<原因>`
- `本地可跑，线上未尝试：<原因>`

## 4. 推荐项目

### 4.1 结构

`games.json` 的四个项目已经验过了，直接照抄：

**抄完之后 Phase 6 仍然有活干**：这四个要真的在代理里跑一遍，确认能嵌、能读到 URL、图片能显示，尤其是 `localStorage` 隔离有没有生效（两个窗口进同一个房间，看游戏里的进度会不会串）。验不过的，把 `embeddable` 改成 `false`，在 `note` 里写原因。

```json
      "minutes": null,
      "hasSearch": false,

    },
    {

      "cover": "",

      "searchParam": "",
      "embeddable": true,

      "url": "https://mp.weixin.qq.com/mp/homepage?__biz=MzYzMjA5MDc2MA%3D%3D&hid=6&sn=e36b7430f1a848019e2e0fc9e8701f7a&scene=305",
      "cover": "",
      "minutes": null,
      "hasSearch": false,
      "searchParam": "",
      "embeddable": false,
      "note": "公众号页面，嵌不了。卡片上不显示，或者显示但点开走新窗口。"
    }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `slug` | 短名，用作 `/setup?preset=<slug>` |
| `title` | 作品名，显示在卡片上 |
| `author` | 作者。不知道就留空，不要编 |
| `url` | 入口地址，空字符串表示还没填 |
| `cover` | 封面图，放 `/public/covers/`，没有就用纯色块 + 标题 |
| `minutes` | 大致通关分钟数，卡片显示 `约 2.5 小时`；`null` 就不显示这一行 |
| `hasSearch` | 有没有站内搜索，决定搜索框的默认语义 |
| `searchParam` | 搜索的 GET 参数名，默认 `q` |
| `embeddable` | 能不能 iframe 嵌入。`false` 的卡片点开走新窗口 |
| `note` | 一句备注，卡片上不显示，配置页显示 |

**四个里只有一个不可嵌。** 微信那条不要为了"整齐"硬塞进 iframe，它会在里面白屏或者跳走。

### 4.2 填一个新项目之前要验四件事

1. **能不能嵌**：`curl -I` 看有没有 `X-Frame-Options` 或 `CSP frame-ancestors`。没有不代表一定行——微信就没返回这两个头，靠 JS 跳。
2. **是不是真的搜索框**：页面里有 `<form>` 不代表是站内搜索。yoroll 那部的输入框是跟 NPC 聊天，`placeholder` 写的也是"请输入关键词"。看 `action` 有没有跳转到结果页，没有就不是。
3. **进度存在哪**：`grep -o "localStorage\|sessionStorage" 首页.html | sort | uniq -c`。存了就必须靠 03 节 e 的前缀隔离兜住，否则房间内所有人共用一份存档。
4. **有没有会炸的外链**：站内有没有 `target="_blank"` 指到站外。有就记下来，别在适配时手动打开。

四个都验完再填。验不了就留空，不要猜。

### 4.3 卡片

首页推荐区用 4.1 的数据渲染。没有 `url` 的项目也要显示，点了提示 `这个还没上线。`——不要隐藏，隐藏了首页就空了。
