## 一、这是什么

一个房间制的网页应用。几个人各自在一个网页解谜游戏里翻找线索，看到什么就丢进房间，别人点开就到那一页。

**三个必须理解的事实：**

- 房间共享的是一条**流**，不是一块屏幕。每个人有自己的浏览器状态，进度各不相同。不要做跟播，不要做同步滚动。
- 游戏是第三方的静态站，用 iframe 嵌进来。我们不改作者的代码。
- 跨域 iframe 读不到 URL。所以做一层 HTML 代理，让"谁到了哪一页"可被感知。这是产品成立的技术前提，不是可选优化。

**用户是谁**：三到六个人，熟人，约好一起玩某个网页解谜。不注册，拿链接就进。

**这类游戏怎么玩**（决定了很多设计）：读页面 → 发现可疑的词或数字 → 在站内搜索框搜它 → 弹出新页面 → 记下来 → 继续。也有一部分作品没有搜索框，全靠点页面里的链接往下走。全程在浏览器里，一部作品 100 到 300 页，两三个小时通关。所以"关键词"和"这页我看过没有"是核心信息。

## 三、技术栈

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 构建 | Vite 6 + React 18 + TypeScript | 不要 Next.js，不需要 SSR |
| 样式 | Tailwind CSS 4 + CSS 变量 | 复杂材质写原生 CSS |
| 后端 | 单个 Cloudflare Worker | 静态资源 + API + 代理 + WS 全在一个 Worker |
| 实时 | Durable Objects + WebSocket | 一个房间一个 DO 实例 |
| 存储 | DO 的 SQLite storage | `ctx.storage.sql`，不用 KV，不用 R2 |
| 图标 | lucide-react | 线性，1.5px 描边 |
| 二维码 | `qrcode`（npm，只用 `toString`） | 不引 UI 库 |
| 布局算法 | `dagre` | 人物关系图，确定性布局 |
| 部署 | wrangler | 见 `06-导出与部署.md` |

**为什么全放一个 Worker**：代理页面必须和主应用同域，否则 iframe 的 `postMessage` 校验和 CORS 全乱。用 Workers Static Assets 把 `dist` 挂在同一个 Worker 下，路由 `/api/*`、`/p`、`/ws/*`，其余走静态资源。

**不要引入**：UI 组件库（MUI/Ant/shadcn 都不要）、状态管理库（React context 够）、ORM、Google Fonts（国内慢，用系统字体）、任何分析脚本。

## 八、项目名与标识

- 界面上的名字：`多人 ARG`
- Worker 名：`multi-arg`
- **应用自己的** localStorage 前缀：`arg:`（引导标记、导出备份、到期提示的日期）
- **注入游戏页的** localStorage 前缀：`__arg:<房间>:<用户>:`（03 §3e，别和上面那个混）
- postMessage 标记：`__arg`

两个前缀是两套东西：`arg:` 存我们自己界面的状态，`__arg:` 是给第三方游戏存档做隔离的。**混用会让游戏存档和界面状态互相覆盖。** 其余旧名字一律不要再出现。

## 九、成本与限额

| 项 | 量级 | 免费额度 |
| --- | --- | --- |
| Worker 请求 | 一个房间一小时约 200 次翻页 | 10 万/天 |
| DO 请求 | 消息数，Hibernation 下很少 | 100 万/月 |
| DO 存储 | 一个房间 100KB 以内 | 5GB |
| 代理流量 | 只走 HTML，一次 20KB，图片不过 | Workers 免费额度内 |

一个房间玩三小时、5 个人分头翻，翻页总量按 500 到 1500 次算，一次 20KB，**10 到 30MB 一个房间**。100 个房间一个月也就 1 到 3GB。这个量级不需要优化，真正要盯的是请求数（免费 10 万/天）。

**要防的是滥用**：`/p` 必须签名，否则会被人拿去当免费代理，一天就能烧掉额度。

## 十、不做

以下一律不实现。用户以后提，也要先问。

- 语音通话
- 截图、图片上传、文件上传
- 账号系统、登录、头像上传
- 局域网模式、局域网发现
- 原生 App、Electron 包壳
- 端到端加密（理由是它会让二维码直接进房这套流程变复杂，而内容只是朋友间的解谜笔记）
- AI 功能（总结笔记、提示线索）
- 深色模式
- 跟播 / 同步滚动 / 共享屏幕
- 房间顶部的"当前目标"条（v2 再说）
- 别人的光标、选区、协作编辑
- 消息推送、邮件通知
