## Phase 1 · 全部静态 UI

做了什么：

- **首页**：字标、40px 主标题、72px 粘贴框（回车进 `/setup`）、推荐横向卡片（无封面用色块 + 首字，不可嵌的走新窗口）、底部「有房间号？」→ 8 位房间号+口令弹窗（自动分组、粘贴邀请码也认）。
- **配置页**：游戏标题/域名、「你的名字」、模块胶囊多选（默认笔记 + 关键词）、`开了全员可见，进房后不能改。`、「开始」全宽主按钮；文案取自 `05 §5`。
- **房间 iPad**：iframe 容器固定 430×932、`scale = min(可用高/932, 可用宽/430)`、居中不随面板变化；右边缘 24px 起手、左移 40px 出五个图标（pin/流/记一笔/模块/邀请，间距 56px、30ms 递延）；面板 360px 绝对定位浮层、`translateX` 进出、默认收起只留 6×96 的缝；分段 流/笔记/图/词/密/时；公共搜索（本地计数 + 「在游戏里搜」+「发给大家」+「词」）；头像条；网页卡（作者色竖线、两行截断、已读标记）；笔记行（星标、排除变灰删除线、评论缩进）；底部输入（快捷语法提示、Enter 发送）；邀请卡（`qrcode.toString` 真生成 SVG、复制链接、支持时显示隔空投送）；新手引导（缝呼吸 → 图标演示 → 底部提示 5 秒）；断线窄条（先由浏览器 online/offline 驱动，Phase 2 换成 WS 状态）；新消息光带；`⌘K` / `⌘N` / `⌘Enter` / `Esc`。
- **房间手机**：iframe 全屏 `100dvh`，底部 36px 毛玻璃传送带（最新一条、截断一行），上滑 / 点击升到 55vh，再上滑到 88vh，下拉收回；面板在抽屉里复用同一套组件；不做边缘缝。
- **四个模块**：人物关系（`dagre` 层次布局、贝塞尔边 + 关系标签、作者色描边）、关键词（`词 = 命中` 输入行、命中/未命中标签可点切换）、密码本（默认打码、点眼睛显示、已验证开关）、时间线（竖线 + 节点按时间排序）。
- 房间里的游戏先用 `public/mock-game.html` 顶替（一个像第三方论坛存档的页面），不依赖代理。
