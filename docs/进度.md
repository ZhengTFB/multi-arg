## 2026-10-31 · 设计修订（用户三条反馈）

### 1. 文案可以在浏览器里改，改完写回文件

- 所有界面文字集中到 `src/copy.json`（81 条），组件通过 `src/lib/copy.ts` 的 `t(key)` 取值，需要点选改的元素带 `data-copy="key"`。
- `?edit=1` 打开校对模式：点任何带 `data-copy` 的文字就地改（contentEditable），底部工具条显示改了几处。
- 「列表」按钮打开全部文案（含占位符这类不在正文里的），可以直接改。
- 保存走 dev 中间件 `POST /__copy/save`（`vite.config.ts` 里 `configureServer`），合并写回 `src/copy.json`，写完自动刷新。构建产物里没有任何写文件能力。
- 验证过程（Playwright）：改标题 → 保存 → 文件中出现新值 → 刷新后页面渲染新值 → 再改回原值，四步都通。

```
toolbar: 1
written: 几个人一起翻同一件案子
rendered: 几个人一起翻同一件案子
list rows: 81
restore: 200 几个人一起玩网页解谜
```

### 2. 流改成聊天

- 每条是一个消息块：头像 + 名字 + 时间 + 气泡；自己发的靠右、深土褐底。
- 同一人 3 分钟内连发不重复头像和名字；跨天才插一条日期分隔（`今天` / `昨天` / `8 月 15 日`）。
- 网页卡变成"链接气泡"：左侧首字色块 + 标题两行 + 域名，点整块进游戏，看过的右上角打勾。
- 评论缩进在父消息下面，带左侧细线；被排除的消息整条变灰加删除线。
- 输入区改成聊天气泡条：更大的输入热区、发送键 34px 圆钮，快捷语法提示只在聚焦时淡入。
- 切到「图 / 词 / 密 / 时」再切回来，输入框草稿不丢（`Composer` 只隐藏不卸载）。
