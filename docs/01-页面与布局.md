## 1. 首页与配置页

### 1.1 `/` 首页

一屏之内，从上到下：

```
多人 ARG                                   字标，左上，24px

几个人一起玩网页解谜                         主标题，40px，墨绿

┌──────────────────────────────────────┐
│ 粘贴游戏链接                          │   输入框，高 72px，全宽
└──────────────────────────────────────┘   视觉主体，最大的一块

推荐                                        小标题，14px，灰

┌────────┐ ┌────────┐ ┌────────┐
│ 封面   │ │ 封面   │ │ 封面   │           横向滚动，卡片 200×140
│ 标题   │ │ 标题   │ │ 标题   │
└────────┘ └────────┘ └────────┘

有房间号？                                   小字，12px，贴底
```

- 输入框粘贴链接按回车 → `/setup?u=<encoded>`。
- 推荐卡片点击 → `/setup?u=<url>&preset=<slug>`。
- "有房间号？"点击 → 弹 4 位数字输入 → `/r/<id>`。
- **不要放营销区块、功能介绍、页脚。** 一屏结束。

输入框的校验：

| 情况 | 提示 |
| --- | --- |
| 不是 http(s) | `这不像一个网址。` |
| 能访问但禁止嵌入（`X-Frame-Options` 或 CSP `frame-ancestors`） | 允许继续，进房后按 03 §8 处理 |
| 打不开 | `这个网址打不开。检查一下链接。` |

### 1.2 `/setup` 配置页

```
游戏
《大学生登山失踪事件》                       读不到标题就显示域名

你的名字
┌──────────────────────────────────────┐
└──────────────────────────────────────┘

这局要开哪些
☑ 笔记   ☑ 关键词
☐ 人物关系  ☐ 密码本  ☐ 时间线
开了全员可见，进房后不能改。

开始                                        主按钮，墨绿，全宽
```

- 进页面调 `POST /api/probe`，抓一次目标站首页：拿 `<title>`、探测有没有禁止嵌入的头、看能不能访问。**不要靠"有没有 **`<form>`**"判断站内搜索**——有的游戏输入框是给 NPC 聊天用的，看着像搜索框（见 06 §4.2）。
- 站内搜索这行只在**推荐项目**上显示：`games.json` 里 `hasSearch: true` 才显示 `这个游戏有站内搜索`。用户自己粘的链接不猜，进房后按 04 §6 的降级逻辑走（搜本地）。
- 名字留空 → `访客一`、`访客二`，按进房顺序编号。
- 点"开始" → `POST /api/room` → 跳 `/r/<id>#<token>`。
- token 放 hash，不放 query。hash 不进服务器日志和 Referer。

**从旧配置创建**（低调入口）：localStorage 里有导出备份时（见 06 §1），页面最底部显示一行 12px 灰字 `用上次的配置新建`。点开是确认弹窗，列出上次的项目和模块，确认后预填。**不要做成按钮，不要用主色。**

## 2. 房间布局

### 2.1 iPad（宽度 ≥ 768 且横屏）

```
┌─────────────────────────────────────────────┐
│                          ┌────────────────┐ │
│   ┌──────────────┐       │ 8472 · 4 人  ⤴ │ │  面板 360 宽
│   │              │       │ ─────────────  │ │
│   │   iframe     │       │ 流 / 笔记      │ │
│   │   430 宽     │       │                │ │
│   │   等比缩放    │       │ [卡片]         │ │
│   │              │       │ [笔记]         │ │
│   │              │       │                │ │
│   │              │       │ ┌────────────┐ │ │
│   └──────────────┘       │ │ 说点什么…  │ │ │
│                          └────────────────┘ │
│                                        ┃    │  那条缝
└─────────────────────────────────────────────┘
```

- 背景取 `05` 里的页面底色，可加一层 40% 以下透明度的噪点。
- iframe 容器固定 **430×932**，等比缩放到可用高度，居中。**圆角和投影按 **`设计参考/`** 里的值**，这里不另写一套。
算法：`scale = min(可用高/932, 可用宽/430)`，`transform-origin: center center`。
`scale < 0.72` 时在 iframe 下加一行小字 `横过来看会大一些`。
- 面板 360px，`position: absolute`，右侧，**不挤占 iframe**。**默认收起**，屏幕上只留那条缝。上面这张图画的是展开态。
- 收起时 iframe 仍然是 430 宽的容器居中，**不因为面板收起而变大**。宽度始终不变，否则每次收放画面都跳一下。
- 第一次进房间时按 2.6 演示一次，之后靠手势唤起。**不要放常驻按钮。**
- 那条缝贴屏幕最右，宽 6px，高 96px，垂直居中，圆角 3px，`rgba(7,68,76,0.14)`。不悬浮时不显示任何图标。

### 2.2 手机（宽度 \< 768 或竖屏）

```
┌──────────────┐
│              │
│    iframe    │   全屏，不缩放
│    占满       │
│              │
│ ┈┈┈┈┈┈┈┈┈┈ │   传送带 36px，半透明玻璃
│ 小林：符咒有… │
└──────────────┘
```

- iframe 全屏，`100dvh`。
- 底部传送带 36px，显示最新一条（截断一行），`backdrop-filter: blur(20px) saturate(180%)`，上方 1px 分隔线。
- 上滑传送带 → 抽屉升起 55vh；再上滑 → 88vh；下拉收回。
- 手机上**不做边缘缝**。iPhone 左右边缘是系统返回手势区，抢不过来。

### 2.3 面板

顶部分段控件（横向，胶囊底槽）：

```
[ 流 ]  [ 笔记 ]  [ 图 ]
```

- 只有开了的模块才出现。全开是"流 / 笔记 / 图 / 词 / 密 / 时"，允许横向滚动。
- **流和笔记是两个东西**：流是按时间混排的全部内容（网页卡、笔记、系统消息），笔记是只看文字笔记、按人分开看。按人分开用的是头像条（04 §2），不是再多几个 tab。
- 分段下方是内容区，独立滚动，`overscroll-behavior: contain`。
- 内容区顶部固定**公共搜索框**，逻辑见 04 §6。
- 底部固定输入行：`说点什么…`，点击展开两行，右侧发送键。

面板头部右端两个东西：

- `8472` — 房间号，等宽字体，点一下打开邀请
- `4 人` — 点开是成员列表，每行：名字、颜色点、`正在看《店内环境》`（有就显示，没有留空）、最后活跃时间

### 2.4 边缘缝的手势（仅 iPad）

```
起手：手指落在右边缘 24px 内
判定：向左位移 > 40px 且水平分量大于垂直分量
结果：四个图标从缝里依次浮出，垂直居中，间距 56px
```

图标顺序：`pin`（钉住这页）、`message`（流）、`pen`（记一笔）、`grid`（模块）、`share`（邀请）。

五个，间距 56px，垂直居中。`share` 放最后，因为面板收起时它是唯一的邀请入口——只有房间号这一条路的话，朋友得先问号再输，比发链接麻烦。

- 浮出用 `cubic-bezier(0.32, 0.72, 0, 1)`，180ms，每个延迟 30ms。
- 点任一图标 → 面板展开并定位到对应区块。
- 点空白处或再划一次 → 收回，图标原路消失。
- **iframe 不位移、不变暗、不缩放。** 硬要求，不满足就是做错了。

### 2.5 邀请

点头部房间号、`⤴`，或缝里的 `share` → 弹出一张卡（320 宽，从右侧滑入，不遮 iframe）。面板收起时直接浮在缝的左边，不需要先展开面板：

```
邀请
8472

┌─────────┐
│  ▓▓▓▓▓  │   二维码，160×160
│  ▓▓▓▓▓  │
└─────────┘

[ 复制链接 ]
[ 隔空投送 ]
```

- 二维码内容：完整进房链接（含 token），不是只有房间号。扫一下直接进。
- "复制链接" → `navigator.clipboard.writeText`，成功后按钮变 `已复制`，2 秒复原。
- "隔空投送" → `navigator.share({ url })`。不支持就隐藏这个按钮。
- 二维码用 `qrcode` 的 `toString(url, { type: 'svg', margin: 0 })`，直接插 SVG，不要 canvas。
- **不要做"发送到微信"之类的假按钮。** 系统分享面板已经在里面了。

口头场景（大家坐一起）：报房间号，对方在首页输 4 位数字进来。这条路必须通，不能只给链接。

### 2.6 新手引导

第一次进房间（`localStorage` 没有 `arg:onboarded`），三件事，总时长 30 秒内：

1. **缝自己亮一次**：0.5 秒后，那条缝轻微呼吸两下（opacity 0.4 → 1 → 0.4），2 秒后停。
2. **图标自己浮出再收回**：1 秒后，四个图标浮出，停 1.5 秒，收回。**只演示一次。**
3. **底部一行提示**：`从右边划一下，能看到大家发的东西。` 5 秒后淡出。

手机版对应改成：传送带向上顶 4px 再回位，提示语 `往上滑，能看到大家发的东西。`

再给一个"重看"入口：成员列表底部一行小字 `重看引导`。

不做多步骤遮罩、不做高亮圈、不做"下一步"按钮。三步都是环境提示，不拦截操作。

### 2.7 新消息怎么提示

不用红点，不用弹窗，不用声音。

| 事件 | 反馈 |
| --- | --- |
| 有人发了东西 | 右边缘一道 2px 的光带从上往下扫一次，1.2 秒消失。手机上是传送带文字换新 |
| 有人 @你 | 面板里那条 item 上方浮一张 44px 的小卡，3 秒后自动收回。点一下跳到那条 |
| 有人加入 | 流里一条系统消息，居中灰字 |
| 断线 | 面板顶部一条 24px 的窄条：`连接断了，正在重连` |
| 重连成功 | 窄条变 `已连上`，1.5 秒后消失 |

光带用 `transform: translateY()` 动画，不要动 `height`。

### 2.8 从流里点开一个网页

- 整张卡就是链接，点哪都进。
- 进之前把当前 iframe 的 URL 记进一个栈（最多 20 条）。
- 跳转后左上角浮一个 `← 回到刚才那页`，**3 秒后淡出**。这是唯一会盖住 iframe 的元素，位置在 iframe 内部左上 12px，胶囊形，玻璃底。
- 点它 → 回退。不点就消失。

### 2.9 键盘（iPad 接外接键盘）

| 键 | 动作 |
| --- | --- |
| `⌘K` | 聚焦公共搜索框 |
| `⌘N` | 聚焦输入框，准备记一笔 |
| `⌘Enter` | 发送 |
| `Esc` | 收起面板 / 关掉弹层 |

没接键盘时不显示任何快捷键提示。

## 3. 进不去的时候

| 情况 | 页面 |
| --- | --- |
| 房间不存在 | `没有这个房间。看看房间号对不对。` + 回首页 |
| 已过期（37 天内） | 正常显示内容，顶部一条灰提示 `这个房间已于 X 月 X 日到期。`，输入框禁用，右上角一个"导出" |
| 已删除（37 天后） | 同"不存在" |
| token 无效 | `这个链接不完整。让房主再发一次。` |
| 被限流（429） | `试得太快了，等一分钟。` |
